# GAME THEORY LAB · 博弈论研究所

移动端优先的博弈论自学站：8 个部分、29 讲结构化讲义、174 道带详解的练习、74 个现实案例、3 个交互实验室、自动错题本与学习进度。

---

## 课程体系

以经典博弈论理论体系为骨架自行撰写讲解，按「是什么 → 怎么算 → 为什么成立 → 怎么用」的认知顺序组织，覆盖从入门到进阶的完整路径。

| 部分 | 主题 | 讲数 | 核心内容 |
| --- | --- | --- | --- |
| 01 | 博弈论基础 | 4 | 研究对象、发展史、四要素与理性假设、分类与建模五问 |
| 02 | 完全信息静态博弈 | 5 | 策略式、收益矩阵、占优与剔除、纳什均衡、多重均衡 |
| 03 | 混合策略与均衡分析 | 4 | 期望收益、无差异条件、2×2 完整求解、存在性与现实意义 |
| 04 | 完全信息动态博弈 | 4 | 博弈树、信息集、逆向归纳、承诺与可信威胁、子博弈完美 |
| 05 | 不完全信息博弈 | 4 | 类型与信念、贝叶斯更新、BNE、信号与筛选、逆向选择与道德风险 |
| 06 | 重复博弈 | 3 | 有限/无限重复、贴现因子、触发策略、合作均衡的形成条件 |
| 07 | 其他重要理论 | 4 | 零和与极大极小、演化博弈与 ESS、机制设计与拍卖、委托代理 |
| 08 | 综合实战 | 1 | 五步建模法、完整实战案例、敏感性分析与验收清单 |

每讲固定包含：学习目标、问题导入、基础概念、理论详解、数学推导、经典模型、完整案例、常见错误、本章知识结构、本章小结、至少 5 道课后练习与详细解析。

重要理论统一回答八个问题：要解决什么、产生背景、包含哪些假设、核心逻辑、如何推导、在什么条件下成立、有哪些局限、能解释哪些现实问题。纳什均衡、混合策略、逆向归纳、贝叶斯纳什均衡等核心内容提供分步推导，不出现「只有结论没有求解过程」的地方。

每个案例都写明参与者、可选策略、收益结构、博弈类型，并单列 `caveat` 说明模型解释不了什么，避免为套理论硬解释现实。

## 交互实验室

| # | 实验室 | 核心计算 |
| --- | --- | --- |
| 01 | 收益矩阵求解器 | 可调四个收益值，自动计算最优反应、占优策略、纯策略纳什均衡与混合均衡概率 |
| 02 | 重复博弈实验 | 可调贴现因子与阶段收益，比较「永远合作」与「今天背叛」的现值，求临界 δ* |
| 03 | 贝叶斯信念实验 | 可调先验与信号精度，用贝叶斯公式更新后验并计算期望收益与最优决策 |

讲义正文、实验室滑杆与测验答案共用同一套验算口径。`npm run verify` 会批量检查矩阵维度、最优反应划线、博弈树节点、题目答案合法性，以及每讲的结构完整性。

## 技术栈

React 18 · TypeScript（strict）· Vite 5 · Tailwind CSS 3 · KaTeX · Recharts

数据全部存在浏览器 LocalStorage，无需登录；已预留云同步适配器接口（`src/lib/sync.ts`）。课程内容或题库更新不会清空学习记录。

## 本地开发

```bash
npm install
npm run dev        # 开发服务器
npm run verify     # 课程结构、矩阵划线、博弈树与计算内核断言
npm run build      # 生产构建
npm run preview    # 预览构建产物
npm run qa         # 浏览器巡检：桌面/手机逐页查报错与溢出，需预览服务在 4380–4395 端口
npm run gate       # 答案门控检查：未作答前页面不得出现答案与解析
```

构建产物在 `dist/`，配合 `base: './'` 与 HashRouter，静态托管无需额外路由回退配置。`npm run deploy` 会先构建，再用 `scripts/deploy.mjs` 通过 Git Data API 把 `dist/` 提交到 `gh-pages`（需 `GH_TOKEN`，目标仓库可用 `GH_REPO` 覆盖）。

## 内容说明

讲义为按知识体系自行撰写的版本，不摘录教材原文，不引用页码。案例中的数字为课堂算例，用于展示计算过程，不构成统计引用。故事化的表述用来帮助理解，结论的成立范围以每讲「假设」与「边界」两节为准。
